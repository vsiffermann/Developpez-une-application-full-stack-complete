
# 🧪 Exercice — Développement d'une application full-stack (MDD)

## 📌 Contexte

Vous êtes recruté en tant que **Lead Developer** chez **ORION**.

L’objectif est de développer un **MVP (Minimum Viable Product)** d’un réseau social pour développeurs appelé **MDD (Monde de Dév)**.

👉 Objectif :
- Mise en relation entre développeurs
- Plateforme de collaboration
- Vivier de recrutement

---

## 🎯 Fonctionnalités principales

- S’abonner à des sujets (JavaScript, Java, Python…)
- Fil d’actualité chronologique
- Création d’articles
- Publication de commentaires
- Authentification utilisateur

---

## 👥 Équipe projet

- Heidi — Développeuse
- Orlando — Responsable
- Juana — UX Designer

---

## 🧩 Mission

Vous devez :

- Choisir les technologies (frameworks, libs, patterns…)
- Développer le front-end et le back-end
- Connecter les deux
- Mettre en place la base de données
- Sécuriser l’application
- Documenter le projet
- Superviser l’utilisation de l’IA

---

# 🪜 Étapes du projet

## 1. Analyse

- Étudier les spécifications
- Analyser le code existant
- Comprendre les maquettes

### Résultat attendu
- Compréhension globale du projet

---

## 2. Architecture

- Définir architecture front/back
- Choisir outils et frameworks
- Définir API (endpoints)

### Résultat attendu
- Documentation technique complète

---

## 3. Environnement

- Configurer projet (Git, IDE, DB)
- Installer dépendances
- Préparer données de test

### Résultat attendu
- Projet fonctionnel localement

---

## 4. Implémentation simple (E2E)

- Créer une fonctionnalité simple
- Connecter front → back → DB

### Résultat attendu
- Chaîne complète fonctionnelle

---

## 5. Fonctionnalités principales

- Implémenter :
  - abonnements
  - articles
  - commentaires
  - fil d’actualité

### Résultat attendu
- Application fonctionnelle (sans design)

---

## 6. UI & Sécurité

- Intégrer maquettes Figma
- Implémenter authentification (JWT recommandé)
- Rendre l’app responsive

### Résultat attendu
- Application utilisable et sécurisée

---

## 7. Tests & Documentation

- Tests :
  - JUnit (backend)
  - Jest (frontend)
  - Cypress (E2E)
- Documentation API
- FAQ utilisateur

### Résultat attendu
- Couverture ≥ 70%
- Documentation complète

---

## 8. Finalisation

- Nettoyage du code
- Respect des bonnes pratiques (SOLID)
- Documentation finale
- Préparation livraison

---

# ⚠️ Contraintes

- Respect strict des spécifications
- MVP simple (pas de sur-ingénierie)
- Cohérence front/back
- Gestion des erreurs
- Code propre et documenté

---

# 🧠 Bonus (IA)

- Déléguer certaines tâches à l’IA
- Vérifier et corriger le code généré
- Documenter l’usage de l’IA

---

# 📦 Livrables attendus

- Repository GitHub
- Code front + back
- API documentée
- Tests
- Documentation technique
- FAQ utilisateur

---

# ✅ Objectif final

Livrer un MVP fonctionnel, propre, documenté et prêt à être présenté.
